## Step 21 — User requested two authenticity features. Realistic multi-step flap travel + sustained clatter delegated to opus now; per-cell colour control queued behind the phase 6 agent on file ownership.

```
Animation gap: current mechanism is a single 90-degree swap in 220ms settling by ~450ms, but a real board only ever moves FORWARD through a fixed flap sequence, so a tile going A->Z passes through every intermediate character and takes far longer than A->B. Design brief therefore makes travel time proportional to forward distance through BOARD_CHARS (~57 chars) with wrapping, which makes the stagger EMERGENT rather than decorative and naturally lands tiles at different moments — no artificial per-tile delay needed. Target window 3-5s implies roughly 55-80ms per step. Hard constraint flagged: 144 tiles stepping every ~60ms is up to ~2400 updates/sec on a Samsung Tizen TV, so it must be ONE rAF loop mutating the DOM via refs with React owning only the target grid, never 144 timers or 144 state updates per step, and the agent must MEASURE frame timings and trade step rate for smoothness if needed. Sound must become a throttled clatter whose rate falls as fewer tiles remain in motion so it thins to a final few clicks — explicitly NOT one clack per tile per step, which would be thousands of overlapping sounds. Also required: mid-travel retarget from wherever each tile currently is, prefers-reduced-motion still an instant silent swap, and the phase 3 verification timings (first tile 117ms, settled 449ms) will be stale afterwards.
```
